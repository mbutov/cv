=== Electronic Transport Documents for a Large Retail and Logistics Company, 07.2026 - 10.2026

#(?) For EU applications the client name is omitted. For other markets use: Komus, one of the largest Russian suppliers of office and business goods#

Role: team lead and lead developer.
Team: #(?) team size#.

The project moves the company's transport paperwork (waybills, carrier requests, forwarding receipts) to electronic documents in the state e-document system by a regulatory deadline.
The system consists of microservices on Java 25, Spring Boot 4, Temporal, and Kafka: an orchestrator, a document lifecycle service, an e-document operator adapter, and adapters for SAP S/4HANA and an in-house ERP.
Production handles about 30,000 electronic waybills a day.

* Redesigned the orchestrator on Temporal: a parent order workflow with child document workflows, an explicit state machine with transition graph validation, and hexagonal architecture with layer boundaries enforced by ArchUnit.
* Implemented transportation scenarios: shipments by sole traders, carriers, and forwarders, two-leg transportation, inbound deliveries, signature waiting with a shared per-order deadline, and partial rejections without stopping the order.
* Kept long-running processes compatible across releases: workflow versioning through a patch registry and a build gate that replays saved production histories.
* Made Kafka processing reliable: infrastructure and data errors handled separately, bounded exponential retries so one failing message never blocks a partition, a dead letter queue, and end-to-end correlation across Kafka and Temporal.
* Defined service contracts in AsyncAPI, OpenAPI, and JSON Schema with code generation and protocol compatibility checks in Gradle convention plugins.
* Hardened integrations with the e-signature service and the e-document operator: concurrency and retry limits after an incident with API gateway rejections, a service pool to reduce load on the external API.
* Built the test infrastructure: Testcontainers, a Docker Compose environment, and end-to-end tests with stubs of external systems and a scenario DSL.
* Set up observability: Temporal tracing with OpenTelemetry, Micrometer metrics, Grafana dashboards, log and trace analysis in Loki and Tempo, a worker scaling plan.
* Led development: release planning, code review across all services, rollout and rollback plans, incident analysis, work with business analysts, onboarding.
* Used AI agents (Claude Code, Cursor, OpenCode) for development, code review, and production analysis.
